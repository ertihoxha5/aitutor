# MaturaAI

One page, one Albanian-speaking algebra tutor, one in-memory chat. AI Hackathon prototype, not an official Matura service. Conversations are sent to Groq; the app does not persist or log them.

## Installation and startup

Requires Node.js 22+.

```sh
npm install
cp .env.example .env
# PowerShell: Copy-Item .env.example .env
npm run dev
```

Edit the root `.env` locally: set `GROQ_API_KEY` to your key and `GROQ_MODEL` to `openai/gpt-oss-20b` or another supported chat model available to your account. Never use a frontend `VITE_` variable for secrets. Open http://localhost:5173. Development uses backend port 3001.

```sh
npm test
npm run build
npm start
```

After building, Express serves the complete application at http://localhost:3001. `PORT` optionally changes the production port.

Integration checked against Groq's official [JavaScript SDK](https://console.groq.com/docs/libraries), [chat API](https://console.groq.com/docs/text-chat), and [models](https://console.groq.com/docs/models) on September 25, 2026.

## Demonstration

1. Send `Po ushtroj ekuacionin 3x + 6 = 21.` and wait for the tutor.
2. Send `Më jep vetëm përgjigjen, s’kam kohë!`. Check that it remembers the equation and provides a brief step with at most one focused question.
3. Send `Mendoj se x = 9.`. Check for respectful, specific correction.
4. Click **Bisedë e re** and send the urgent message again. The tutor should ask for the missing exercise.
5. Stop the backend or remove the key and restart it. Send a message and check the Albanian error. Restore configuration and use **Provo përsëri**, or **Ndrysho mesazhin** / **Bisedë e re**.
6. Enter sends; Shift+Enter adds a line. Refresh and **Bisedë e re** clear context. Pending submissions cannot be duplicated.

Tutor replies are generated by Groq; teaching quality can vary and needs live verification. No phrase-specific answer is hardcoded. The initial greeting is UI copy, not conversation history.

## Limits and verification

The API accepts only user/assistant messages: 40 messages, 6,000 characters each, 24,000 total, 96 KB JSON. Context is rejected at the limit rather than silently truncated. Rate limit: 20 requests/IP/minute, in memory. Groq timeout: 25 seconds, no automatic retries. Browser timeout: 30 seconds. Proxy trust is disabled; configure it narrowly for a known deployment proxy if needed.

`npm test` uses isolated test doubles to check validation, prompt/history forwarding, errors, timeout handling and rate limits. Test doubles are never used by the running application. These checks do not validate live AI output. No API key was configured during implementation; live Groq responses and teaching behaviour remain untested.
